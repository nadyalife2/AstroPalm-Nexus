# 🌌 AstroPalm Nexus (Натальная Карта + Компьютерная Хирология)

**AstroPalm Nexus** — профессиональный веб-комплекс и MCP-сервер для высокоточного расчета натальных карт на базе **Swiss Ephemeris** (Швейцарские Эфемериды NASA JPL), компьютерного биометрического анализа кисти руки (**Computer Vision / OpenCV**) и их глубокого герметического синтеза по матрице классических первоисточников (*Уильям Г. Бенхам, Л.Г. Штернберг, Адольф Дебаролль, Казимир д'Арпентиньи*).

---

## ✨ Основные модули и возможности

### 1. Астрологический вычислительный движок (Swiss Ephemeris)
- **Точность эфемерид:** алгоритмический расчет координат 12 небесных тел (Солнце, Луна, Меркурий, Венера, Марс, Юпитер, Сатурн, Уран, Нептун, Плутон, Северный Узел, Хирон) с субдуговой точностью.
- **Домофикация:** строго классическая система домов **Плацидуса (Placidus)**, расчет ASC, MC, DSC, IC.
- **Аспекты и рецепции:** вычисление мажорных аспектов с динамическими орбисами, баланс 4 стихий и крестов качеств.
- **Динамический транзитный радар (30 дней):** автоматический расчет точных моментов пиковой кульминации транзитных планет к натальным точкам.

### 2. Компьютерная хирология и 4-х ракурсная студия (Computer Vision & Geometry)
- **4-х ракурсная загрузка:** Правая (Ладонь), Правая (Снаружи/Тыл), Левая (Ладонь), Левая (Снаружи/Тыл).
- **Анатомическая корректность:** строгое разделение проекций большого пальца (для правой ладони — палец справа, для левой — слева; кнопка быстрого горизонтального зеркального отражения `🔄 Отразить руку`).
- **OpenCV Crease Extraction (Детекция складок):** выделение темных долин кожных борозд методом CLAHE и Black-Hat морфологии.
- **Врожденная ментальная независимость:** автоматическое измерение дистанции между истоком Линии Головы и Линии Жизни. При разрыве $\ge 15\,\text{px}$ система фиксирует классический маркер ранней самостоятельности мышления.
- **Онихогномия и замер суставов:** анализ формы ногтевой пластины и профиля среднего пальца (узлы PIP и DIP) с вычислением коэффициента узловатости.

### 3. Классические трактаты и эзотерический синтез
- **👑 7 Планетарных Архетипов Уильяма Г. Бенхама (1900, *The Laws of Scientific Hand Reading*):** вычисление ведущего и вспомогательного холмов ладони с подбором идеальных карьерных призваний и зон здоровья.
- **⚖️ Три Мира фаланг и Королевский Большой Палец (Л.Г. Штернберг & А. Дебаролль):** диаграммы распределения энергии по трем сферам (ментальная, практическая, материальная) и формула баланса Воли (1-я фаланга) и Логики (2-я фаланга).
- **9 Алгоритмических критериев конвергенции:** вычисление математического Индекса Резонанса Систем (62–98%), выявление подтвержденных талантов и точек роста с практическими ключами трансформации.
- **⏳ Хронологический мост жизни (0–70+ лет):** синхронизация датировки линий ладони по шкале Беньхама с астрологическими кризисами взросления (возвраты Сатурна, оппозиции Урана, юпитерианские фазы).

### 4. Интерактивный Canvas-интерфейс
- **Живая адаптация сетки:** возможность прямого перетаскивания холмов мышкой или касанием по экрану.
- **Манипуляторы линий (Draggable Anchors):** светящиеся маркеры для ручной регулировки истоков и изгибов линий Головы, Жизни и Сердца в реальном времени.
- **Панель калибровки:** кнопки `[✂️ Раздельное начало]`, `[🔗 Слитное начало]`, `[🎯 Автоподгонка]`, `[🔄 Отразить руку]`, ползунки масштаба и смещения.
- **Оценка эволюции (Левая vs Правая):** сопоставление врожденной матрицы и сознательно наработанных качеств.
- **Экспорт:** скачивание структурированного Markdown-отчета и поддержка браузерной печати.

### 5. MCP-сервер (`mcp_server.py`)
Полноценная интеграция с Claude Desktop, Antigravity, Cursor и любыми MCP-клиентами через FastMCP.
Экспортируемые инструменты:
- `geocode_city`
- `calculate_natal_chart`
- `get_transits`
- `get_transits_range`
- `analyze_palm`
- `synthesize_reading`

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск веб-приложения
Дважды щелкните по `run.bat` или выполните:
```bash
python -m uvicorn app:app --host 127.0.0.1 --port 8000 --reload
```
Откройте в браузере: **http://127.0.0.1:8000**

### 3. Запуск MCP-сервера
```bash
python mcp_server.py
```

Конфигурация для Claude Desktop / Antigravity MCP:
```json
{
  "mcpServers": {
    "astro-palm": {
      "command": "python",
      "args": ["d:\\натальная карта\\mcp_server.py"]
    }
  }
}
```
